# CV Louis Daviet

Site portfolio statique présentant mon parcours, mes compétences et mes projets data.

## Aperçu

- **Mon parcours** (`index.html`) : présentation, compétences, expériences, formations et contact
- **Mes projets** (`projects.html`) : détail de projets professionnels et académiques

## Technologies

- HTML5 / CSS3
- [Font Awesome](https://fontawesome.com/) (icônes)
- [Google Fonts](https://fonts.google.com/) (Roboto)

## Lancer en local

Aucune dépendance à installer. Ouvrir `index.html` dans un navigateur, ou servir le dossier avec un serveur statique :

```bash
python -m http.server 8000
```

Puis ouvrir [http://localhost:8000](http://localhost:8000).

## Structure

```
cv-louis-daviet/

├── projects.html    # Page projets
```
